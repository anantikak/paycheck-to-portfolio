# Paycheck to Portfolio

Free, source-checked money basics for high schoolers: budgeting, saving, credit, and investing, with calculators and a quiz.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
It's a static site, so any static host works (GitHub Pages, Netlify, Vercel, Cloudflare Pages). No build command; publish this folder as is.

## Content rules
See `CLAUDE.md`. Every fact must cite a primary source and pass the review step before it's deployed.
